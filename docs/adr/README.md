# Architecture Decision Records

Durable, one-decision-per-file records. Short by design — a few lines of context,
the decision, and its consequences. Written as decisions are made and validated in
code, not upfront.

Specs in `docs/superpowers/specs/` are ephemeral working artifacts; ADRs here are the
permanent record. See `docs/GIT-WORKFLOW.md` (Specs & Decision Records).

Format: `NNNN-kebab-title.md`, numbered sequentially.
